How an AI runs inside your browser

WebGPU Chat has no inference server. The site is a set of static files and your browser does all the work. Here is how it works inside.

1. WebGPU: the graphics card from the web

WebGPU is the modern browser API for using the GPU, both for drawing and for computing. A language model is mostly matrix multiplications, exactly what a GPU is good at. Before anything else the app checks that your browser has WebGPU and that the GPU supports 16-bit numbers (shader-f16), and reads the maximum buffer size to block models that will not fit.

2. 4-bit quantized models in ONNX format

A 4-billion-parameter model takes 8 GB at 16 bits. Quantized to 4 bits (q4f16) it drops to about 2.8 GB without losing too much quality. The models are stored in ONNX format and downloaded straight from Hugging Face, always at the same pinned version, so what you run is exactly what was tested. The largest model, Gemma 4 12B, we exported ourselves from the official weights and validated against the original in PyTorch.

3. Transformers.js and ONNX Runtime Web

Inference runs in a Web Worker, so the page never freezes, with Transformers.js v4 and ONNX Runtime Web in WebGPU mode. Each model uses its official chat template, including the reasoning mode when turned on.

4. Key-value cache kept between turns

A language model remembers what it has read in a key-value cache. The app keeps it between messages, so each answer only processes what is new instead of the whole conversation. Each answer’s statistics show how many tokens were reused.

5. Everything stays on your device

Conversations are stored in IndexedDB and models in the browser cache. A service worker stores the site too, so everything works offline after the first download.

Frequently asked questions

Which browsers have WebGPU?

Chrome and Edge from version 113 on desktop, Chrome 121 or later on Android, and Safari 26 on macOS, iOS and iPadOS.

Why is there no CPU mode?

On the processor these models would manage a few words per second, too slow to chat.

Where is the code?

On GitHub, under the MIT licence: github.com/amintikk/webgpu-chat.
